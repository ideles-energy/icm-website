# icm.energy

Static website for the Independent Capacity Market, served with GitHub Pages (`CNAME` → icm.energy).
Design follows the Canva draft (night blue, teal cards, cyan headings, lilac buttons).

| Path | Page |
| --- | --- |
| `/` | BESS Benchmark landing page (English) |
| `/nl/` | Same page in Dutch |
| `/methodology/` | BESS Benchmark methodology v1.0 (English) |

Shared files: `styles.css`, `main.js` (contact form → Formspree `mbdqdpql`), `assets/`, `robots.txt`, `sitemap.xml`.
